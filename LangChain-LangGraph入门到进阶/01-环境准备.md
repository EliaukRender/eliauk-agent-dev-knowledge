# 01 · 环境准备

> **本章目标**：搭好 Python 开发环境，拿到大模型 API Key，跑通第一个 LangChain 程序。
>
> **前置知识**：会用终端执行命令；会一点点 Python 语法（变量、函数、`import`）即可。

---

## 一、安装 Python 与包管理工具

### 1.1 版本要求

LangChain 1.x 和 LangGraph 1.x 都要求 **Python ≥ 3.10**，推荐 **3.12**。

```bash
python3 --version
```

> ⚠️ macOS 自带的 Python 通常是 3.9，**版本不够**，不要直接用它装包。

### 1.2 推荐使用 uv 管理环境

> 📖 **uv**：一个用 Rust 编写的 Python 包管理器，速度极快，能同时管理 **Python 版本**、**虚拟环境**和**依赖**。可以理解为 Python 界的 `pnpm` + `nvm`。

> 📖 **虚拟环境（Virtual Environment）**：每个项目独立的一套 Python 和依赖，互不干扰。类似前端每个项目有自己的 `node_modules`。

```bash
# 安装 uv（macOS / Linux）
curl -LsSf https://astral.sh/uv/install.sh | sh
# 或者用 Homebrew
brew install uv

# Windows（PowerShell）
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

### 1.3 创建练习项目

```bash
# 创建项目，并指定 Python 3.12（uv 会自动下载）
uv init my-langchain-lab --python 3.12
cd my-langchain-lab

# 安装核心依赖
uv add langchain langchain-deepseek python-dotenv
```

依赖说明：

| 包 | 作用 |
|---|---|
| `langchain` | 主包，会自动带上 `langchain-core` 和 `langgraph` |
| `langchain-deepseek` | 接入 DeepSeek 模型（本教程学习阶段统一使用）。用其他模型就换成对应的包（见第四节） |
| `python-dotenv` | 从 `.env` 文件读取 API Key |

运行脚本：

```bash
uv run hello.py
```

> 💡 `uv run` 会自动使用项目的虚拟环境，不需要手动激活。如果你更习惯传统方式，可以 `source .venv/bin/activate` 后直接 `python hello.py`。

<details>
<summary>不想用 uv？传统 pip 方式</summary>

```bash
python3.12 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -U langchain langchain-deepseek python-dotenv
python hello.py
```

</details>

### 1.4 编辑器

推荐 **VS Code** + 官方 Python 扩展，或者 **PyCharm**。在 VS Code 中按 `Cmd/Ctrl + Shift + P` → `Python: Select Interpreter`，选中项目下的 `.venv`。

> 💡 **Jupyter Notebook** 也很适合边学边试：`uv add --dev ipykernel` 后，在 VS Code 中新建 `.ipynb` 文件即可。

## 二、获取 API Key

> 📖 **API Key**：调用大模型服务的"密码"，用来识别身份和计费。**泄露就等于别人可以用你的钱。**

| 服务商 | 获取地址 | 环境变量名 |
|---|---|---|
| **DeepSeek（本教程默认）** | https://platform.deepseek.com | `DEEPSEEK_API_KEY` |
| Anthropic（Claude） | https://console.anthropic.com | `ANTHROPIC_API_KEY` |
| OpenAI | https://platform.openai.com | `OPENAI_API_KEY` |
| 阿里云百炼（通义千问） | https://bailian.console.aliyun.com | `DASHSCOPE_API_KEY` |

> 💡 **本教程学习阶段统一使用 DeepSeek**：注册简单、价格便宜、国内直连、支持工具调用和结构化输出，足够跑通全部示例。熟悉之后，改一行模型配置就能换成其他厂商。

## 三、用 .env 管理密钥

在项目根目录创建 `.env` 文件：

```bash
# .env —— 只填你实际使用的
DEEPSEEK_API_KEY=sk-xxxxxxxx
# ANTHROPIC_API_KEY=sk-ant-xxxxxxxx
# OPENAI_API_KEY=sk-xxxxxxxx
# DASHSCOPE_API_KEY=sk-xxxxxxxx

# LangSmith 追踪（可选，强烈推荐，见第五节）
# LANGSMITH_TRACING=true
# LANGSMITH_API_KEY=lsv2_xxxxxxxx
# LANGSMITH_PROJECT=my-langchain-lab
```

**立刻**把它加入 `.gitignore`：

```bash
echo ".env" >> .gitignore
```

> ⚠️ **安全红线**：API Key 绝对不要写死在代码里，也不要提交到 Git。已经泄露的 Key 要第一时间到控制台作废。

在代码开头加载：

```python
from dotenv import load_dotenv

load_dotenv()  # 读取 .env，写入环境变量；LangChain 会自动从环境变量里拿 Key
```

## 四、配置大模型

LangChain 1.x 推荐用 **`init_chat_model`** 统一创建模型。它的好处是：**换模型只改一个字符串，其他代码一行不动。**

格式：`"提供商:模型名"`

### 4.1 DeepSeek（本教程默认）

```bash
uv add langchain-deepseek
```

```python
from langchain.chat_models import init_chat_model

# 读取环境变量 DEEPSEEK_API_KEY
model = init_chat_model("deepseek:deepseek-flash", extra_body={"thinking": {"type": "disabled"}})
```

DeepSeek 模型选型：

| 模型 | 定位 | 适合 |
|---|---|---|
| `deepseek-flash` | 快速便宜，支持图片输入（**教程默认**） | 绝大多数学习示例、分类抽取、Agent |
| `deepseek-v4-pro` | 更强，不支持图片输入 | 复杂推理、高质量写作、需要"大模型"的场景 |

> ⚠️ **注意**：旧教程中的 `deepseek-chat`、`deepseek-reasoner` **已于 2026-07 停用**，请使用上表中的新模型名。

#### 为什么要加 `extra_body={"thinking": {"type": "disabled"}}`

> 📖 **术语**：**思考模式（Thinking Mode）**：模型在给出答案前，先生成一段"内心推理过程"（`reasoning_content`），推理更强，但更慢、更贵。DeepSeek 的模型**默认开启**思考模式。

本教程**统一关闭思考模式**，原因有三：

1. **工具调用会报错**：DeepSeek 要求开启思考模式且带工具时，必须把每一轮的 `reasoning_content` 原样传回，否则返回 `400`。而 `langchain-deepseek`（当前 1.1.x）**不会自动回传**它，第 05 章之后的工具调用、Agent 示例都会失败。
2. **参数会失效**：思考模式下 `temperature` 等参数不生效，第 02 章讲的参数就没法体验。
3. **更快更省**：学习阶段的示例不需要深度推理。

> 💡 `extra_body` 的意思是"把这些字段原样塞进请求体"。`thinking` 是 DeepSeek 特有的参数，LangChain 没有为它单独提供参数名，所以通过 `extra_body` 传入。

> ⚠️ **注意**：`create_agent(model="deepseek:deepseek-flash")` 这种**直接传字符串**的写法没法附带 `extra_body`，所以本教程中凡是需要传模型的地方，都传入用 `init_chat_model(...)` 创建好的模型实例。

model = init_chat_model("anthropic:claude-sonnet-5")  # 读取环境变量 ANTHROPIC_API_KEY

### 4.3 通义千问（OpenAI 兼容接口）

很多国内模型都提供 **OpenAI 兼容接口**，可以直接借用 OpenAI 的接入包，只需改 `base_url`：

> 📖 **OpenAI 兼容接口**：接口格式和 OpenAI 一模一样的 API。因为 OpenAI 的格式成了事实标准，很多厂商都支持这种格式，方便开发者无缝切换。

```bash
uv add langchain-openai
```

```python
import os
from langchain.chat_models import init_chat_model

model = init_chat_model(
    "openai:qwen-plus",
    base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
    api_key=os.environ["DASHSCOPE_API_KEY"],
)
```

> 💡 同样的方法适用于 Kimi、智谱 GLM、硅基流动等支持 OpenAI 兼容接口的服务，换成它们的 `base_url` 和模型名即可。

### 4.5 本地模型（Ollama）

> 📖 **Ollama**：在自己电脑上运行开源大模型的工具，免费、离线、数据不出本机，但效果和速度取决于你的电脑配置。

```bash
# 先安装 Ollama（https://ollama.com），然后拉取模型
ollama pull qwen3:8b
uv add langchain-ollama
```

```python
model = init_chat_model("ollama:qwen3:8b")
```

> ⚠️ 小参数量的本地模型在**工具调用**和**复杂 Agent** 场景下表现明显较差，学习 Agent 相关章节时建议用云端模型。

### 4.6 推荐写法：把模型配置集中起来

为了让后续所有练习都能一处切换模型，建议在项目里建一个 `config.py`：

```python
# config.py
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model

load_dotenv()

MODEL_NAME = "deepseek:deepseek-flash"  # 换模型只改这里
NO_THINKING = {"thinking": {"type": "disabled"}}


def get_model(**kwargs):
    return init_chat_model(MODEL_NAME, extra_body=NO_THINKING, **kwargs)
```

之后的练习里可以写 `from config import get_model`。本教程的示例为了能单独运行，仍然直接写 `init_chat_model(...)`，你按自己的习惯选择即可。

## 五、配置 LangSmith（强烈推荐）

> 📖 **LangSmith**：LangChain 官方的观测平台。开启后，你的每一次调用都会被记录：发给模型的完整 Prompt、模型返回了什么、调用了哪些工具、花了多长时间、用了多少 Token。

> 💡 **为什么强烈推荐**：学习 Agent 时，最大的困惑往往是"它到底在想什么？为什么调用了这个工具？"。LangSmith 能让你**看清每一步**，相当于 AI 应用的 Chrome DevTools。

开启方式：

1. 到 https://smith.langchain.com 注册（有免费额度）。
2. 在 Settings → API Keys 创建 Key。
3. 在 `.env` 中加入：

```bash
LANGSMITH_TRACING=true
LANGSMITH_API_KEY=lsv2_xxxxxxxx
LANGSMITH_PROJECT=my-langchain-lab
```

**不用改任何代码**，LangChain 会自动上报追踪数据。

> ⚠️ 开启后，Prompt 和输出内容会上传到 LangSmith 服务器。处理敏感数据时请注意合规，或者使用自托管版本。

### 再进一步：第一个 Agent（预览）

下面这段代码会在第 07 章详细讲解，这里先感受一下"10 行代码做出能调用工具的 Agent"：

```python
from dotenv import load_dotenv
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model

load_dotenv()


def get_weather(city: str) -> str:
    """查询指定城市的天气。"""
    return f"{city}今天晴，25°C"


agent = create_agent(
    model=init_chat_model("deepseek:deepseek-flash", extra_body={"thinking": {"type": "disabled"}}),
    tools=[get_weather],
    system_prompt="你是一个乐于助人的助手，用中文回答。",
)

result = agent.invoke({"messages": [{"role": "user", "content": "杭州今天适合出门吗？"}]})
print(result["messages"][-1].content)
```

模型会自己判断需要查天气 → 调用 `get_weather("杭州")` → 根据结果回答"适合出门"。

## 七、常见问题

| 问题 | 原因与解决 |
|---|---|
| `ModuleNotFoundError: No module named 'langchain_deepseek'` | 没装对应的接入包，执行 `uv add langchain-deepseek`；或者运行脚本时没用项目的虚拟环境 |
| DeepSeek 返回 `400`，提示缺少 `reasoning_content` | 没有关闭思考模式就使用了工具调用 / Agent。按 [4.1 节](#41-deepseek本教程默认) 加上 `extra_body={"thinking": {"type": "disabled"}}` |
| DeepSeek 提示模型不存在 | 旧模型名 `deepseek-chat` / `deepseek-reasoner` 已于 2026-07 停用，改用 `deepseek-flash` 或 `deepseek-v4-pro` |
| `AuthenticationError` / `401` | API Key 错误、未加载（忘了 `load_dotenv()`），或者环境变量名写错 |
| `Unable to infer model provider` | `init_chat_model` 的模型字符串缺少 `提供商:` 前缀 |
| 连接超时 / `Connection error` | 网络无法访问该服务商。国内网络建议改用国内模型 |
| `RateLimitError` / `429` | 请求太频繁或额度不足，检查账户余额或降低并发 |
| 安装报 Python 版本不兼容 | Python 低于 3.10，用 `uv init --python 3.12` 重建项目 |
| 网上教程的代码跑不通 | 很可能是 0.x 旧写法，参见 [14 章 FAQ](./14-FAQ与学习资源.md) 的新旧写法对照 |
